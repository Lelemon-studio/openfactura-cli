# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En corto: trata a los demás con respeto, critica ideas y no personas, y no acoses a nadie. Aplica en los
issues, los pull requests y cualquier espacio del proyecto.

Para reportar una conducta inaceptable, escribe a contacto@lelemon.cl. Los reportes se revisan con
reserva, y quien reporta no sufre represalias.
